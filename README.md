# Titanic Analysis: The "From Scratch" Approach 🚢

A pure Python implementation of the classic Titanic Machine Learning challenge.

**The Twist:** This project explicitly **avoids** data science libraries like `pandas` or `numpy`. Instead, it solves the problem using Python's built-in data structures (lists, dictionaries, classes) to master the fundamentals found in Chapter 2 of Joel Grus's book, *Data Science from Scratch*.

## 🎯 Project Goal
To understand the "magic" behind data libraries by building the data processing tools manually. This project focuses on:
* **Raw Data Parsing:** Reading CSVs and type-casting strings manually.
* **Data Structures:** Using Lists of Dictionaries vs. Classes.
* **Pythonic Logic:** Utilizing List Comprehensions and Generators.
* **OOP:** Encapsulating data in custom `Passenger` classes.
